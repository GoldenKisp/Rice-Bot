### Information

### Features
```ini
[+] Embedded Help Command
[*] Moderation Features
  [+] Kick users
  [+] Ban users
  [+] Purge messages
[*] Fun Features
  [+] 8ball
  [+] Ricefacts ; sends fun facts about rice
  [+] Wikipedia search ; utilizes wikipedia's API to generate responses
```

### Required Modules
```ini
py-cord
```
